# Third-party reference and attribution

The profile's two-column infographic layout is inspired by [lowlighter's GitHub profile](https://github.com/lowlighter). Its isometric contribution renderer is an independent Python adaptation of the projection in [lowlighter/metrics](https://github.com/lowlighter/metrics/blob/366f8b9dfe3a59656c67d5dcad9950f59c9bc96d/source/plugins/isocalendar/index.mjs).

The local reference was read from `D:\Work\metrics` at commit `366f8b9dfe3a59656c67d5dcad9950f59c9bc96d`. That repository was not modified. No personal artwork, language data, achievements, sponsorship information, or identity from lowlighter's profile is copied into this profile.

The optional workflow uses the native Metrics action at that same pinned revision. The bootstrap image renderer is not the native Metrics engine. It uses real public GitHub data and produces a usable local profile before a Metrics personal token is configured.
